# Synthetic Document and Dataset Generator

Generates realistic, clearly watermarked synthetic Indian KYC and financial documents for training and testing the Intelligent KYC Platform.

## Synthetic Constraints
- Every generated document includes a diagonal watermark: `SYNTHETIC SAMPLE - FOR DEMO ONLY`.
- Identifiers use realistic formats (Aadhaar with valid Verhoeff checksums, standard PAN formatting).
- No real personally identifiable information (PII) is ever created or utilized.
